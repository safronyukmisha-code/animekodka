# Telegram-бот "видео по коду"

Бот хранит видео прямо в Telegram и выдаёт их по короткому коду.
Например: пишешь `клип1`, бот присылает нужное видео с названием.

## 1. Создать бота

1. Напиши в Telegram [@BotFather](https://t.me/BotFather).
2. Команда `/newbot`, задай имя — получишь токен вида `123456:ABC-DEF...`.

## 2. Узнать свой Telegram ID (чтобы стать админом)

Напиши [@userinfobot](https://t.me/userinfobot) — он покажет твой ID.

## 3. Установить зависимости

```bash
pip install -r requirements.txt
```

## 4. Запустить бота

Через переменные окружения (рекомендуется):

```bash
export BOT_TOKEN="твой_токен_от_BotFather"
export ADMIN_IDS="твой_telegram_id"
python bot.py
```

Либо просто впиши `BOT_TOKEN` и свой ID в `ADMIN_IDS` прямо в начале файла `bot.py`.

Если `ADMIN_IDS` не задан вообще — добавлять видео сможет любой (удобно, пока тестируешь в одиночку, но потом лучше ограничить).

## 5. Как пользоваться

**Добавить видео (только админ):**
Отправь боту видео с подписью в формате:
```
клип1 | Смешной момент из стрима
```
Код (`клип1`) — то, по чему потом будут искать. До `|` — код, после — название.

**Найти видео (любой пользователь):**
Просто напиши код текстом, например:
```
клип1
```
Бот пришлёт видео с названием.

**Посмотреть все коды:**
```
/list
```

**Удалить код:**
```
/del клип1
```

## 6. Чтобы бот работал постоянно (не только пока открыт терминал)

Варианты:
- Оставить запущенным на своём ПК (пока комп включён и запущен скрипт — бот работает).
- Задеплоить на сервер (например VPS): загрузить эти файлы, поставить Python 3.10+, `pip install -r requirements.txt`, запускать через `screen`, `tmux` или как systemd-сервис, чтобы бот не падал при перезагрузке.
- Бесплатные варианты для старта: Railway, Render, Fly.io — залить репозиторий, задать переменные окружения `BOT_TOKEN` и `ADMIN_IDS`, запустить `python bot.py` как worker-процесс.

Если захочешь — могу подробно расписать деплой на конкретную платформу.

## Важно про лимиты Telegram

Через Bot API боты могут отправлять видеофайлы размером **до 50 МБ**. Если нарезки больше — надо будет либо сжимать видео, либо хранить их не в самом Telegram, а по ссылке (на своём хостинге/облаке), и бот будет присылать ссылку вместо файла. Скажи, если нужен такой вариант — переделаю логику.
